# Privacy Notice — Letter League

**Short version:** Letter League does not require registration and does not ask for email addresses, phone numbers, real names, location, contacts, or social logins. It has no advertising, analytics, tracking pixels, or in-game chat.

## Data used during a game

To make a multiplayer room work, the service temporarily processes:
- A nickname chosen for the current room.
- A random temporary player token generated by the browser.
- Room code, board, game settings, submissions, scores, and connection-related state.

The application stores this state in a Supabase database row while the room is active. It is not intended to create player profiles or retain game histories. Rooms expire after three hours of inactivity and expired rows are deleted opportunistically by the backend. Scheduled cleanup should be configured where available. This is temporary server-side storage, not a promise that all infrastructure backups or provider logs are immediately erased.

## Technical information

GitHub Pages, Supabase, and network infrastructure providers may process technical connection metadata such as IP addresses, request timestamps, browser information, and security logs under their own privacy policies and retention practices. The application does not intentionally collect precise location or access contacts.

## Browser storage

A random temporary player token and nickname may be stored in the browser's session storage to support the current session. They are not used for advertising or cross-site tracking. Closing the tab/session may clear them.

## Third parties

- GitHub Pages hosts the website.
- Supabase provides database and Realtime infrastructure.
- The interface uses system fonts and does not intentionally load a third-party font service.

Each provider has its own privacy policy, operational logs, and retention practices. Review those policies before sharing the game.

## Children's use

The game is designed for family play, but the operator should supervise children's use and avoid entering real names or sensitive information as nicknames.

## Contact

This starter repository does not include a contact form or collect an email address. The repository owner may add a contact method if needed.
